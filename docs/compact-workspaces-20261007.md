# Compact classroom workspaces, October 7, 2026

The course selector and lesson search stay directly above the reader. The
redundant course hero and collapsed course-control panel are removed.

The IDE explorer starts collapsed and expands to compact project/file rows.
Code and Scratch selection sits beside the workspace title. Associated course
project and active file remain visible; rename, diagnostics and ZIP backup
move into settings. Save and Run remain directly available, with usable touch
targets. Storage notices and local-save protection commentary are removed.

This is a selective downstream adaptation, not a merge of business features.
The five public classroom courses, archived references, anonymous access,
optional student project sync, teacher-only administration, and shared-device
handoff protections remain. No Graph Sketcher, booking, email, tutor roster,
Zoom or account-email workflow is imported.

Version 2.8.4 changes no dependency resolutions, database schema, credentials
or host runtime. Validate and deploy the exact annotated tag through the
existing native workflow. Keep the prior immutable release for rollback.
Local and CI results do not establish production activation.

Tests use synthetic accounts and intercepted APIs. They send no real mail and
do not change student records. The release metadata is synchronized across
the existing native and optional fallback definitions; no container execution
is required by this change.
