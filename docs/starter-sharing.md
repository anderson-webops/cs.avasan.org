# Classroom starter links and project sharing

Current public course cards offer **Copy starter link** beside the existing
starter launch link. Share this link through the school's approved classroom
channel to open the same original classroom starter on another device. It does
not publish or copy the sender's edited project. If the recipient already has
a matching saved code project, the IDE may resume that local project without
overwriting it. A denied or unavailable clipboard shows a selectable link for
manual copying.

The link comes only from a starter declared in one of the five current public
courses, not the current browser URL or an IDE project. Scratch IDs must appear
in the shipped starter catalog. Python-family links retain only the public
catalog's launch metadata, including its public starter key when required to
load source files. Descriptive title/label parameters are removed. Solutions,
archived references, unknown parameters, student IDs, files, code, uploaded
assets and account details are not inputs to this feature.

To transfer edited work now, download the project (`.sb3` for Scratch, ZIP for
the code workspace), use a school-approved transfer method, and import it on the
receiving device. Check the file for real names or other personal information
before sending it. No project-sharing upload or public student-project route
is added.

## Specifically deferred: links to edited student projects

Generic edited-project links remain **to do**, not delivered by starter-link
copying. Before implementing them, obtain:

- The school's authorization for this additional disclosure of student work,
  with the responsible school/privacy approver identified.
- A product decision on approved recipients and access: for example, Julio-only
  review or individually authenticated recipients. Do not assume publicly
  readable URLs are approved.
- Approved expiry, revocation and deletion/retention rules, including what
  happens to previously downloaded copies and when the owner is removed.
- Approved handling of names, uploaded media and other personal information;
  a review/confirmation step and the applicable student/guardian notices or
  permission, if required by the school.

Implementation can then be scoped and reviewed against that workflow. Student
account activation or consent to private project sync alone does not approve
public project publication.

## Specifically deferred: complete reference-teacher resource copies

The organized Scratch sequence, original starters and original artwork are
already present. They are an adaptation, not a complete copy of the reference
teacher's website; see [Scratch classroom authorship](scratch-classroom.md).
Before fulfilling a request to copy particular resources onto both sites,
provide:

- The exact teacher/page URLs and list of lessons, projects, images and media
  to preserve, and the requested destination on each site.
- Original downloadable files for resources that are private, inaccessible or
  not available from those pages.
- The license or rightsholder's permission for each resource, including
  redistribution/adaptation on both sites, required attribution and any
  noncommercial/share-alike conditions. Permission for MyCS material does not
  establish permission for proprietary Juni material.

Review the supplied set, preserve its provenance and attribution, then adapt
only compatible material. Do not scrape or redistribute an unspecified entire
site, private projects or student work, and do not publish non-Scratch teacher
solutions to learners.
